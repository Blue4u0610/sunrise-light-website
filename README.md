# Sunrise Light

A lightweight bilingual coming-soon page for **sunriselight.net**.

## Website

- Primary domain: https://sunriselight.net
- Alternate domain: https://www.sunriselight.net
- Hosting: GitHub Pages

## Update the website

Edit `index.html` and commit to `main`. GitHub Pages publishes the repository root automatically. No package installation or build step is required.

`CNAME` configures the custom domain. Keep it unless you are intentionally changing the domain.

## Project scope

This is a temporary informational landing page, with English and Chinese text. It has no transactions, accounts, forms, analytics, third-party scripts, or backend services.

GitHub Pages availability may vary by visitor network. Test from the intended audience's networks before relying on it for a production business website. Future commercial functionality requires reviewing the hosting provider's permitted uses.

## Files

- `index.html`: complete page, styles, and CSS illustration.
- `CNAME`: custom hostname.
- `.nojekyll`: serves files without Jekyll processing.
